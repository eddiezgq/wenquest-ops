# WenQuest Ops

AI-native operations platform for small and mid-sized businesses, built on ERPNext.

- One base, one data graph: orders, inventory, purchasing and quality connected
- Modules turn on as needed: quality, warehousing & distribution, production, and more
- AI drafts, people confirm
- Companies build and customize it themselves with AI, following our step-by-step courses

Status: planning Phase 1. See `docs/plan.md` (Chinese).
