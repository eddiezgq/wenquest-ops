看板把整个业务一次呈现出来。上面的每个数字都是 WenQuest Ops 根据 ERPNext 和它自己的记录统计出来的；没有任何估算，
背后没有数据的数字显示“未知”。每次与 ERPNext 同步（每 5 分钟）之后它会自动刷新；有变化的数字会短暂亮一下。

![演示公司的看板](img/dashboard.webp)

**从采购订单到付款。** 这是业务链：采购订单、收货、来料检验、库存、生产、放行、发货、开票和收款。每个环节显示当前在那里的内容；
红色的环节有东西卡住了（采购订单已过要求到货日期、批次等待太久、订单延误、发票逾期未付）。点击环节即可打开。
客户退回的投诉和召回显示在链的末端上方。

**指示灯。** 业务的每个部分一盏灯。颜色由一个数字和贵公司的目标决定：

| 指示灯 | 依据的数字 |
| --- | --- |
| 销售 | 本周订单与之前各周平均值的比较 |
| 发货 | 最近 30 天按时发货的销售订单 |
| 库存 | 未结订单缺货的物料 |
| 采购 | 最近 30 天按时收货的采购订单行 |
| 生产 | 最近 30 天放行、且没有步骤不合格的批次 |
| 质量 | 逾期的质量事项：纠正预防措施步骤、投诉上报期限、校准 |
| 财务 | 应收账款中逾期部分的占比 |

绿色表示达标，黄色表示需要留意，红色表示需要处理，灰色表示数据不足。目标值只是起点：由负责人设定公司自己的目标。
把鼠标移到指示灯上可以看到它的目标。

**面板。** 业务的每个部分各有一个面板，包含关键数字、8 周、13 周或 26 周的曲线，以及背后的订单、物料或客户。
财务（发票、应收、应付）只显示给有权查看的人（默认是负责人）。

**等待处理。** 等您处理的事项：要阅读的文件、要确认的草稿、要放行的来料批次和生产批次、要批准的变更、风险文件和校准，
以及显示为红色的逾期质量事项。

**每日简报。** 每天早上 7:30（公司时间）系统会写一份简短的简报；用“每日简报”打开。

**大屏。** “大屏”把看板全屏显示在办公室或车间的电视上：大号字体，每 20 秒换一个画面（方向键切换，空格键暂停，F 键全屏，
Esc 退出）。访客模式默认开启，除非负责人关闭；在访客模式下，大屏不显示任何金额，也不显示客户或供应商名称：
只显示占比、数量和曲线走势。
