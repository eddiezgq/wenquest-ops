WenQuest Ops 位于 ERPNext 旁边。ERPNext 保存您的订单、库存、采购和账务；WenQuest Ops 每隔几分钟读取一次，
把它们连成一幅完整的业务图景，并指出需要关注的地方。

**在这里您可以做什么**

- **看板**：从采购订单到付款的业务链、业务各部分的指示灯、每周曲线、等您处理的事项、每日简报，以及今天发现的问题。
  每个角色只看到允许看的部分。
- **助手**：用日常语言提问；它根据您的数据回答，并准备草稿。
- **异常**：规则发现的问题，每个都附有原因和影响范围。
- **草稿**：为您准备好的采购订单、消息和报告；在有人确认之前，什么都不会发生。
- **记录**：“质量”（不合格品报告、8D、纠正措施、控制图）、“投诉”、“来料检验”、“合格供应商”、“测量设备”、
  “变更”、“风险”、“生产”、“追溯与召回”、“管理评审”和“质量体系”，能查看质量记录的人在侧栏里各有一项。
- **文件**和**我的阅读**：文件库，以及等您阅读的文件。
- **对象**：浏览和搜索所有内容：订单、物料、供应商、收货、检验。

**系统坚守的三条规则**

1. 数字来自您的记录，并说明是怎样统计的。缺数据就显示“未知”，绝不显示为 0。
2. 助手只准备草稿。写入 ERPNext 或对外发送任何内容，都要有人确认。
3. 质量决定用您的密码签字，签字后不能修改，只能注明原因后作废。

**您的角色决定您能看到什么。** 销售人员看到订单和库存，看不到供应商的详细信息；质量人员看到检验和供应商。
如果需要更多权限，请找负责人。

**跟着导览走一遍。** [新手导览](#tour)用两分钟带您看一遍您的角色会用到的页面。
