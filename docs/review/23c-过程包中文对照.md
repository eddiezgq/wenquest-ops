# 过程包中文对照（ADR-0023 第 23c 步，请项目负责人审核）

- 条款号与国际标准相同；“要求摘要”是我们自己的概括，不是标准原文（与英文版同一规则）。中文摘要按英文逐句译出，没有加减内容。
- 采标号已核实：GB/T 19001-2016 等同采用 ISO 9001:2015；医疗器械原定的 YY/T 0287-2017 已作废，现行的是 **GB/T 42061-2022**（等同采用 ISO 13485:2016，2023-11-01 实施），系统里用后者。
- ISO 9001 的 2024 年第 1 号修正（气候变化）国内标准未见对应修改单，所以写成“ISO 9001:2015（含 2024 年第 1 号修正）/ GB/T 19001-2016”。
- 审核看三点：① 采标号写法；② 过程名称用语；③ 摘要意思有没有不对。要改直接在对话里说，改在 `wqops/locales/zh.json`。
