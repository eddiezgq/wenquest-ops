# ADR-0030：爆炸图由 FreeCAD 插件生成，送到 PLM 待人确认

- 状态：已接受（2026-11-15，项目负责人：G7.1 后半段细则“好”，第 5 条“33b 爆炸图”）
- 日期：2026-11-15
- 关联：WenQuest 仓库《实施细则 · 第 135 轮》33b、《第 138 轮》G7.1 后半段；ADR-0026（FreeCAD 推送设计数据）

## 背景

第 124 轮的配件手册，爆炸图是在 PLM 网页里手动拉开、截图；第 135 轮定：每个部件都用 FreeCAD 生成真正的三维爆炸图，
印刷版要黑白矢量线条图，网页和电子版用彩色立体图；工程师在自己的 FreeCAD 里一键生成，服务器不装 FreeCAD；人在 PLM 里确认。

## 决策

1. **FreeCAD 插件加“生成爆炸图”**（`freecad/WenQuestPLM/wqplm_explode.py`）。选一个装配，插件先问 PLM 这个装配的 BOM 行
   （`GET /api/integration/v1/plm/explode/{编码}`，钥匙权限 `plm:send`），按编码把装配里的零件对上 BOM 行，然后：
   - **拉开**：最大的零件（机壳、主轴）不动；装配是长条形时，在它轴线上的零件沿轴向滑出，其余从它的中心向外推，
     每个推到不和已放好的零件相碰为止，近的先放；轴承这类标准件跟着最近的零件走；螺钉等紧固件编号、列表，不画。
   - **序号气泡**：号码就是 BOM 行号，从图中心向外放，互相避开。
   - **线条图**：等轴测方向（从左前上方看），FreeCAD 的消隐（`TechDraw.projectEx`），只出可见线，写成 SVG（矢量）；
     另出一张同样的 PNG。
   - 送到 PLM（`POST /api/integration/v1/plm/explode/{编码}`）：每个零件挪多远（mm，装配坐标，**整个拉开量**）、
     气泡、观察方向、SVG、PNG。不连网也能跑（无界面方式批量出图，演示数据就是这样做的）。
2. **PLM 收到后是“待确认”**。服务器核对：气泡号码和 BOM 行号一致（不一致说明出图后 BOM 改过，要重新生成）；SVG 只许
   有线条和文字（没有脚本、外链、事件、实体），不超过 5 MB；页面显示 SVG 时再加沙箱。
3. **彩色图同源**：PLM 爆炸图页用插件送来的同一组挪动量（自己的自动拉开量设为 0）、同一观察方向画彩色三维；
   页面上可以在“线条图 / 彩色图”之间切换。人点“确认”时，把看到的彩色图（连气泡）存为这一页的图。
4. **只有确认过的页进配件手册**；线条图（SVG）留着给印刷版（33c）。在网页里手动改过再保存的，就成了普通网页页，
   不再带线条图。
5. 每次送来、确认都记日志（谁、什么时候、多少个气泡）。

## 后果

- 数据库 053：`plm_explodes` 加 `state`（pending / confirmed）、`source`（browser / freecad）、`svg_sha`、`line_sha`、
  `confirmed_by`、`confirmed_at`。原有页面都算已确认、来自网页。
- 插件只用 FreeCAD 自带的 Part、TechDraw 和 Qt，不另装东西；钥匙沿用 `plm:send`。
- 蓝湾演示：18 个有三维的部件，用这个插件无界面批量生成（`demo/plm/wqls_explode.py`），装入时工程师确认 17 页，
  留一页（WQ88-1710 标准旋梭部件，不在 TED 手册里）待确认，给看演示的人点。
