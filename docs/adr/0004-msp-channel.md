# ADR-0004：IT 部门与 IT 服务商（MSP）是部署者和销售渠道

- 状态：已接受（2026-10-12，项目负责人：“大部分中小企业要么有 IT 部门，要么有提供服务的 IT 服务商”；“同意”）
- 日期：2026-10-12
- 补充：ADR-0001

## 背景

美国中小企业的系统多由一两个人的 IT 部门或外包的 IT 服务商（Managed Service Provider，MSP）部署和维护；老板拍板，
IT 去装、去管。一家 MSP 通常服务几十家小企业，管电脑、网络、Microsoft 365、备份，也在找能多给客户提供的服务。
项目负责人一个人撑不住大量部署和售后。

## 决策

1. **三类人**：老板（买单、定目标）、AI 专员（使用、定制）、IT 部门或 MSP（部署、维护）。
2. **MSP 合作计划**：我们提供部署课程、认证、运维文档和技术资料；MSP 给客户部署、维护并向客户收服务费；
   我们收课程费和接口订阅费，可给 MSP 返点。具体条款在第 0 期访谈 MSP 后再定。
3. **产品对 IT 友好**（第 1 期起）：
   - 部署、备份、恢复、升级、监控标准化，配完整的英文运维文档（第 3 项）；
   - 支持 Microsoft 365（Entra ID）和 Google Workspace 账号登录（OpenID Connect，第 4 项）；
   - 一个 MSP 集中管理多个客户实例：第 2 期以后。
4. **第 0 期访谈**加 1–2 家本地 MSP。

## 后果

- 售后与部署可以由 MSP 分担，项目负责人只支持 MSP
- 课程多一类：给 IT 与 MSP 的部署与运维课
