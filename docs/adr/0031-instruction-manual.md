# ADR-0031：使用说明书在 PLM 里由 AI 起草、人逐章确认

- 状态：已接受（2026-11-15，项目负责人：G7.1 后半段细则“好”，第 7 条“33d 使用说明书”；施工细则写在 WenQuest 第 138 轮）
- 日期：2026-11-15
- 关联：WenQuest 仓库《实施细则 · 第 135 轮》33d；ADR-0030（爆炸图）

## 决策

1. **章节固定 8 章**：安全须知、开箱与安装、各部分名称、穿线与绕线、操作（针距、倒缝、压脚）、日常保养（加油、清洁）、
   常见故障与处理、技术参数。每章中文、英文各一份正文，加插图。挂在整机（有 BOM 的自制件）的零件页上。
2. **AI 只起草**：依据型号和选配、BOM 里的部件和零件名（含已确认的英文名）、已确认的爆炸图、已确认的其他章节。
   提示词规定不编数值、设定、电压、重量、油品和零件，缺的写“〔待填 to be filled〕”；起草结果是草稿，运行留记录
   （`ai_runs.kind = plm-manual`）。模型由部署决定：国内用备案模型，美国用 Claude。
3. **人逐章确认**；改了已确认的章节，它回到草稿。只有确认过的章节进版次；一章都没确认不能出版次。
4. **插图**：只许这台机器下已确认的爆炸图（印刷版用线条图，电子版有彩色图就用彩色图），或人上传的 PNG / JPG。
5. **版次定格**（`plm_um_editions`，改、删都被数据库拒绝），印刷版、电子版两份 PDF，与配件手册同一套版式和字体。
6. **经销商链接**沿用配件手册的只读链接：链接页上多一个“使用说明书”，指向最新版的电子版 PDF。

## 后果

- 数据库 055：`plm_um_chapters`、`plm_um_editions`；`ai_runs` 的种类加 `plm-manual`。
- 蓝湾演示：TED 型 8 章事先写好（数值取 WQ-LS 示例设计值，没有的写“待填”），装入时保存、确认，出第 1 版。
