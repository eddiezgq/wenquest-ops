# ADR-0013：网页界面采用 Frappe 的设计与组件库（frappe-ui）

- 状态：已接受（2026-10-13，项目负责人：“这些表面文章也很重要，要做好”“按建议，同意风格”）
- 日期：2026-10-13
- 补充：ADR-0002（复用）、ADR-0007（运营中枢网页）

## 背景

第 1 期验收时项目负责人指出：WenQuest Ops 的网页与 ERPNext 风格不一致，也不如后者美观。现有网页是为跑通功能写的
简单样式。企业用户会在两边来回切换，两边看起来应是同一个产品。

## 决策

1. **用 Frappe 官方的 Vue 组件库 frappe-ui**（MIT 许可；ERPNext 新一代应用 Helpdesk、CRM 等都用它），版本固定，
   连同它要求的 Tailwind CSS 3。只用它的界面组件与设计规范（字体、颜色、间距、按钮、表单、表格、标签、对话框、
   下拉菜单、图标），不用它连接 Frappe 后端的部分：数据仍来自中枢自己的 API。
2. **布局对齐 ERPNext**：左侧边栏导航（公司名、各模块、图标，可收起），页面顶部标题栏放面包屑和主要操作，
   个人菜单（我的账号、帮助、引导、退出）在侧边栏底部。手机宽度下侧边栏变为抽屉。
3. **只改外观，不改功能**：页面内容、权限、流程不变；现有测试、CI 冒烟测试（按需改选择器，不放宽检查）、
   帮助截图都要通过并重录。
4. **分两步**：
   - 13a 公共框架（侧边栏、标题栏、主题、字体）与仪表盘，截图给项目负责人确认风格；
   - 13b 其余页面逐页换成 frappe-ui 组件：异常、对象、草稿、助手、质量各页、帮助、人员与账号、登录页。
5. **不另造设计**：颜色、圆角、字号用 frappe-ui 的设计变量；我们自己的样式只补它没有的（如控制图、追因链）。

## 后果

- 前端依赖增加（frappe-ui、Tailwind）；按版本锁定，升级单独评估
- 与 ERPNext 观感一致，课程截图与教程可统一风格
- 自绘图表（趋势、控制图、追因链）的配色改用同一套设计变量
