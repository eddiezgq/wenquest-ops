# ADR-0018：公司全局仪表盘与大屏

- 状态：已接受（2026-10-15，项目负责人：“供应商改为来料或进货PO，加销售和财务数据，最好都用动态的图表，曲线等表示，可以有大屏模式，客人来访时有冲击力”）
- 日期：2026-10-15
- 补充：ADR-0007（数据网与本体）、ADR-0013（界面）、ADR-0017（受监管模块）

## 背景

现在的仪表盘是 6 个数加一段晨报：看不出各环节之间的关系，也看不出趋势。WenQuest Ops 的价值在“中枢”：
ERPNext 的订单、库存、采购和我们的质量、生产、追溯记录连成一张网。仪表盘应当一眼看到公司的整体情况，
用图表和曲线动态展示；来访客人看大屏时要有冲击力。

## 决策

1. **七个板块，各一盏灯**：销售、交付、库存、进货（采购单与来料）、生产、质量、财务。每盏灯绿 / 黄 / 红，
   旁边写出决定颜色的数；颜色由确定性规则按阈值判定，**阈值是公司配置**（预置值标明“按贵公司的目标调整”）；
   数据不够时灯为灰色“未知”，不判绿。
2. **每个板块的数（确定性计算，可点开看怎么算、来自哪几单）**：
   - 销售：按周的订单金额与单数（已提交的销售订单）、前几位客户；
   - 交付：准时交付率（已有）、逾期订单；
   - 库存：库存金额、库存天数、缺货物料（已有）；
   - 进货：采购单按时到货率（已有的供应商按时率改名并按单统计）、在途采购金额、来料检验待检批数与拒收率；
   - 生产：在制批、待放行批、每周放行批数、一次合格率（17i）；
   - 质量：未关闭不合格与 CAPA、逾期措施、未结投诉、ISO 控制点满足 / 不满足 / 未知；
   - 财务：按周开票金额、应收余额与逾期应收、应付余额（ERPNext 销售发票、采购发票）。
3. **业务链流程图**：进货单 → 收货 → 来料检验 → 库存 → 生产 → 放行 → 发货 → 开票 → 回款。每一环显示当前数量和卡住的单
   （红点），流动方向用动画表示；点一环展开卡住的单，再点进记录。投诉、召回从客户端回连，不合格与 CAPA 挂在出问题的环节上。
4. **趋势图**：每个关键数配 8 周（可选 13 / 26 周）曲线，标出与上周相比的升降。
5. **需要人处理**：汇总各模块等人的事（待签字、逾期、待确认的 AI 草稿），按紧急程度排序，每人只看到自己权限内的。
6. **动态**：每次 ERPNext 同步完成后（默认 5 分钟）自动刷新；变化的数字短暂高亮，新出现的问题标“新”。动画只用来表现
   变化和流向，不为装饰；每个数都能点开。
7. **大屏模式**：`/wall`，全屏、深色、大字号，每页约 20 秒自动轮播（全局 → 销售与财务 → 交付与库存 → 进货与生产 → 质量），
   自动刷新。**来访模式**是公司开关，默认打开：大屏上不显示金额和客户、供应商名称，只显示比例、趋势和数量；
   需要显示金额时由老板关掉这个开关。
8. **图表库**：Apache ECharts（Apache-2.0 许可），只在仪表盘和大屏页面按需加载，不影响其他页面。
9. **同步范围增加** ERPNext 的销售发票和采购发票（本体 `finance` 域已有定义，由“待接入”改为“已同步”）；
   重新录制 ERPNext 真实回复供回放测试；演示企业补上发票。只读，不写 ERPNext。
10. **权限**：新增“查看财务数据”权限，默认给老板；没有这个权限的人看不到财务板块（发票、应收、应付）。其余板块按现有权限
    显示，金额与各角色在本体里已能看到的一致（如销售看订单金额、仓库看库存金额）。
11. **原则不变**：所有数字和颜色都由确定性代码算，AI 不参与；晨报保留（折叠在页面右上）。

## 分步

- 18a：本 ADR 与计划
- 18b：同步销售发票、采购发票；演示数据补发票；重新录制回放
- 18c：汇总接口（七个板块、流程链、趋势、待办）、阈值与来访模式配置、财务权限
- 18d：新仪表盘页面与大屏模式

## 后果

- 老板和来访客人一眼看到公司全貌，各模块的数据在一处汇合，体现“中枢”
- 新增一个图表依赖（约 1 MB，按需加载）
- 同步范围扩大，需要重新录制 ERPNext 回复；发票较多的企业第一次同步会多用几分钟
