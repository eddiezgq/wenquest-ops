# ADR-0003：语言、单位、AI 提供方

- 状态：已接受（2026-10-12）
- 日期：2026-10-12

## 决策

1. **语言**：界面英文为主，留中文切换（vue-i18n，文案集中在语言文件）；代码与注释英文；计划与 ADR 中文。
2. **单位与格式**：内部数量按 ERPNext 的计量单位原样保存，不自行换算；显示按企业清单设置（美元、美国日期格式
   MM/DD/YYYY、时区）；重量、长度的英制或公制由企业选择。
3. **AI 提供方**：默认 Claude（Anthropic API）；网关保留可换提供方的接口。DeepSeek 不作为美国客户的默认选项。
   密钥只从环境变量读；每次 AI 运行记录输入摘要、输出、确认人。
4. **测试**：不调用真实 LLM，用录制的回复；不联网。

## 后果

- 中文用户（以后的国际客户）也能用，但第 1 期只保证英文完整
