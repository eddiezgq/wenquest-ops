# ADR-0002：从数字工厂复用什么；ERPNext 数据怎么进来、怎么写回

- 状态：已接受（2026-10-12）
- 日期：2026-10-12
- 补充：ADR-0001

## 背景

数字工厂（`freecad-ai-parts/factory/digital`）约 1.5 万行枢纽代码、15 个领域的本体定义、40 多个网页。
它的本体由仿真车间经消息总线推送的事件建成；企业安装版（ADR-0063/0064）已经能一键装 ERPNext 与工作台。
两个仓库都归项目负责人所有，可以直接复制代码。

## 决策

1. **复制，不依赖**：需要的代码复制到本仓库后改写为英文、通用，不从 `freecad-ai-parts` 导入；每个复制来的文件开头注明出处。
2. **第 1 期复用**：

   | 来源 | 用途 | 改动 |
   | --- | --- | --- |
   | `factory/enterprise/`（安装、备份、升级、Caddy、ERPNext 编排） | 部署 | 去掉总线、仿真、PLC；美国默认值 |
   | `factory/factory/plant.py`（工厂清单、Excel 导入） | 企业清单 `company.yaml` | 从“工作站、工序”改为“地点、仓库、部门、角色” |
   | `hub/accounts.py`、`erp_sso.py` | 账号、角色、ERPNext 单点登录 | 角色改为通用岗位 |
   | `ontology/*.yaml`、`hub/ont/` | 运营中枢：本体、对象浏览、异常、追因、提醒、复盘 | 数据来源改为 ERPNext；先用客户、销售、产品、供应、仓储、质量、人员、财务 8 个领域 |
   | `hub/llm.py`、`llm_gateway/`、`hub/ont/agent.py` | AI 助手 | 英文提示词；默认 Claude，可换其他提供方 |
   | `hub/qproblem.py`、`spc.py`、`Q8D.vue`、`Quality.vue` | 质量 | 加不合格品、纠正预防、来料检验、供应商质量 |
   | `web/src/pages/Help.vue` 与录制工具 | 英文帮助、操作视频 | 内容重写 |

   不进第 1 期：仿真车间、消息总线、虚拟 PLC、3D 车间、CAD/CAE、课程接口、教学功能。
3. **数据进来**：同步器按 `modified` 时间增量拉取 ERPNext 单据（物料、仓库、库存台账、销售订单、发货单、采购订单、
   采购收货、质量检验、客户、供应商），每次变化记成一条事件，本体由事件重放得到（沿用数字工厂“事件 → 本体”的做法）。
   以后可加 ERPNext webhook 缩短延迟。
4. **写回 ERPNext**：只经 REST API 建草稿（Draft）单据，由有权限的人在界面上确认提交；AI 不能直接提交。

## 后果

- 中枢不必等实时消息，几分钟延迟对中小企业够用
- 本体、追因、提醒等最费功夫的部分可以复用，主要工作是换数据来源与英文化
